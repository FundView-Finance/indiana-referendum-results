# Indiana public school referendum results

The data file behind [fundviewk12.com/referendums](https://fundviewk12.com/referendums): every public school referendum on the November 3, 2026 Indiana ballot, with yes and no percentages, called status and the source for each row.

`data.json` is updated through election night and again as counties certify. All results are unofficial until certified. Sources are named in the file and on the page: county election boards as reported by IASBO, WRTV, Chalkbeat Indiana and Mirror Indy.

Published by FundView Finance LLC.
